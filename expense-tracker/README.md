# 💰 מעקב הוצאות

אפליקציית טלפון (אייפון + אנדרואיד) למעקב אחרי הוצאות חודשיות. בנויה עם Expo / React Native.

## מה יש בגרסה הזו
- הוספת הוצאה: סכום, קטגוריה (9 קטגוריות) והערה
- סיכום חודשי: סה״כ, פירוט לפי קטגוריה עם פסים צבעוניים, ורשימת כל ההוצאות
- מעבר בין חודשים
- גרף הוצאות של 6 חודשים אחרונים: השוואה לחודש הקודם, ממוצע חודשי, ולחיצה על עמודה עוברת לאותו חודש
- לחיצה על הוצאה פותחת עריכה (סכום, קטגוריה, תאריך, הערה) ומחיקה; לחיצה ארוכה מוחקת
- בחירת תאריך: היום / אתמול / שלשום, או חיצים יום אחורה/קדימה
- תקציב חודשי לכל קטגוריה (לשונית 🎯 תקציב), עם התראה ב-80% ובחריגה, ופסים בצבע ירוק/כתום/אדום
- הנתונים נשמרים בטלפון עצמו (גם אחרי סגירת האפליקציה)

## איך מריצים בטלפון
1. מתקינים בטלפון את **Expo Go** (מה-App Store או מ-Google Play).
2. במחשב (צריך Node.js מותקן):
   ```bash
   cd expense-tracker
   npm install
   npx expo start
   ```
3. סורקים את קוד ה-QR שמופיע: באייפון עם המצלמה, ובאנדרואיד מתוך Expo Go.

אפשר גם לפתוח בדפדפן במחשב: `npx expo start --web`
